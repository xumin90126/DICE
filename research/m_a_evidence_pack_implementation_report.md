## Evidence State Is Availability State, Not Semantic Interpretation

```
EVIDENCE_STATE_IS_AVAILABILITY_STATE = TRUE

  EXTENT_EXISTS:
    Means: "A drawing extent observation exists on this page"
    Does NOT mean: "This drawing is the one the text describes"
    Does NOT mean: "This is a figure"
    Human still judges: "Is this text associated with this drawing?"

  PRIMITIVES_NO_EXTENT:
    Means: "Drawing primitives were observed but did not form an extent"
    Does NOT mean: "This page has no figure"
    Does NOT mean: "The primitives are not a drawing"
    Human sees: drawing elements exist but system couldn't aggregate them

  NO_VISUAL_EVIDENCE:
    Means: "No drawing primitives or extents were observed on this page"
    Does NOT mean: "This page has no figure"
    (Figure could be raster image, or on another page)
    Human sees: no vector drawing evidence on this page
```
