# Contributing

## Welcome

This is a research project. Contributions are welcome in the following areas:

- Reproducibility improvements
- Test coverage
- Documentation
- Synthetic data design
- Methodology discussion

## Before Contributing

1. Read docs/data-policy.md - no enterprise or proprietary data may be submitted.
2. Read docs/reproducibility.md - understand the research methodology.
3. Ensure your contribution does not include secrets, PII, or company-specific data.

## Process

1. Open an issue describing your proposed change.
2. Discuss the approach.
3. Submit a pull request referencing the issue.

## Code of Conduct

Be respectful. This is a research community.
